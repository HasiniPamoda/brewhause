# Brewhaus Coffee ☕

A warm, interactive coffee shop web app built with React and Tailwind CSS.

## Planned Features
- Interactive menu with search and filters
- Shopping cart
- User accounts (login / register)
- Reviews and photo gallery

## Tech Stack
- React (Vite)
- Tailwind CSS
- React Router
- Node.js, Express, SQLite (backend, coming later)

## Getting Started
    npm install
    npm run dev
